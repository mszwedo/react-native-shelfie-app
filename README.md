# Shelfie App

A demo app to learn React Native, Expo, native components, routing, navigation, styling, and authentication.

## Installation

```
npm install
```

## Run App

Download Expo Go to your phone.

Run Expo Go in your terminal

```
npx expo start
```

Use your phone to scan the QRCode in the terminal to test the app

or view the app with the url provided in the terminal

## Backend powered by Appwrite.io

Create a free account at appwrite.io

Create a new Project

Create a new App (Select Andriod or iOS)

Copy the values it gives you for 

```
PROJECT_ID
PROJECT_NAME
ENDPOINT
PLATFORM
```

Create a .env.local file based on the .env.example file and copy the values into it

Next you can create a books Database and add columns for title, author, description, and userId
